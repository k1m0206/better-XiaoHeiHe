小黑盒首页信息流（刷新）接口文档
该接口用于获取首页推荐帖子的列表，支持分页加载。

URL: https://api.xiaoheihe.cn/bbs/app/feeds
Method: GET
Auth: Cookie 认证（通过浏览器自动携带）
1. 请求参数 (Query Parameters)
| 参数名 | 类型 | 说明 | 示例 | | :--- | :--- | :--- | :--- | | `offset` | Int | 分页偏移量。**刷新时设为 `0`**；翻页时传入上一页返回的末尾索引。 | `0` | | `pull` | Int | 动作标识。`0` 通常代表首次进入或普通刷新。 | `0` | | `heybox_id` | String | 用户唯一标识。 | `<heybox_id>` | | `hkey` / `nonce` | String | 安全校验签名与随机数，防止非法调用。 | - | | `os_type` / `app` | String | 环境标识，固定为 `web` 和 `heybox`。 | `web` |
2. 响应数据结构 (Response Body)
| 路径 | 类型 | 说明 | | :--- | :--- | :--- | | `result.links` | Array | **核心字段**。包含当前页所有的帖子列表。 | | `result.links[].linkid` | Long | 帖子的唯一 ID。 | | `result.links[].title` | String | 帖子标题。 | | `result.links[].description` | String | 帖子正文摘要。 | | `result.links[].create_at` | Long | 帖子发布时间，Unix 秒级时间戳。 | | `result.links[].imgs` | Array | 图片 URL 列表（支持多图显示）。 | | `result.links[].user` | Object | 发帖人信息（昵称、头像、勋章、等级）。 | | `result.links[].up` | Int | 点赞数。 | | `result.links[].comment_num` | Int | 评论数。 | | `result.links[].hashtags` | Array | 帖子关联的话题标签（如 "steam游戏"）。 |

3. AI Bot 使用约定

开启“评论首页推荐帖”后，AI Bot 后台会按当前轮询周期请求该接口：

| 项 | AI Bot 取值 |
| :--- | :--- |
| `pull` / `offset` | 固定使用 `pull=0&offset=0` 查询首页第一屏推荐。 |
| `heybox_id` | 从当前网页登录 Cookie 中读取。 |
| `os_type` / `app` / `device_id` 等环境参数 | 优先复用插件捕获到的真实网页端 API 参数。 |
| `hkey` / `_time` / `nonce` | 每次按当前接口路径实时生成，不复用历史请求。 |
| 选帖规则 | 从 `result.links` 中取第一条包含 `linkid` / `link_id` / `id` 的有效帖子。 |
| 去重规则 | 仅在主评论发送成功后把帖子 ID 写入本地永久记录，之后不再重复评论该帖子。 |

选中帖子后，AI Bot 会继续调用帖子详情和评论区接口补全上下文，再调用 `comment/create` 以 `reply_id=-1&root_id=-1` 发送普通主评论。
