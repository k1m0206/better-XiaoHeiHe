# 对帖子和评论进行回复

该接口用于向帖子发布新评论或回复已有评论。

URL: `https://workshopapi.xiaoheihe.cn/bbs/app/comment/create`

Method: `POST`

Content-Type: `application/x-www-form-urlencoded;charset=utf-8`

## 请求参数

### URL 参数

用于身份校验与环境识别：`heybox_id`、`hkey`、`_time`、`nonce`、`_rnd`、`os_type`、`app`、`client_type`、`x_client_version`、`web_version` 和 `version`。

### 表单参数

| 字段名 | 类型 | 必填 | 说明 |
| :--- | :--- | :--- | :--- |
| `is_cy` | Integer | 是 | 是否插眼评论，普通评论传 `0`。 |
| `link_id` | Long | 是 | 关联的帖子或动态 ID。 |
| `reply_id` | Long | 是 | 回复目标评论 ID；发布普通主评论时为 `-1`。 |
| `root_id` | Long | 是 | 楼中楼根评论 ID；发布普通主评论时为 `-1`。 |
| `text` | String | 是 | 评论或回复的文字内容。 |

## 响应数据结构

| 路径 | 类型 | 说明 |
| :--- | :--- | :--- |
| `status` | String | `ok` 表示成功。 |
| `commentid` | Long | 新生成的评论 ID。 |
| `floor` | Integer | 新评论楼层号。 |
| `result.comment.comment[0]` | Object | 评论详情，用于前端回显。 |
| `result.reply_push_state` | Object | 评论消息推送状态。 |

后端根据 `reply_id` 和 `root_id` 区分普通主评论与楼中楼回复。请求签名中的 `nonce`、`hkey` 和 `_rnd` 应按当前请求动态生成；请求成功后可直接使用返回的评论详情更新页面。

## 网页端真实请求参考

以下样例来自网页登录态下的真实请求。Cookie 中的登录凭据已脱敏，调试时应使用当前浏览器实际 Cookie，不要复用文档中的占位值。

```bash
curl 'https://workshopapi.xiaoheihe.cn/bbs/app/comment/create?app=heybox&heybox_id=<heybox_id>&os_type=web&x_app=heybox_website&x_client_type=web&x_os_type=Windows&x_client_version=&client_type=web&web_version=3.0&version=999.0.4&hkey=<hkey>&_time=<timestamp>&nonce=<nonce>&_rnd=15%3A<rnd_signature>' \
  -H 'Origin: https://www.xiaoheihe.cn' \
  -H 'Referer: https://www.xiaoheihe.cn/' \
  -H 'content-type: application/x-www-form-urlencoded;charset=utf-8' \
  -b 'user_pkey=<user_pkey>; user_heybox_id=<heybox_id>; heybox_id=<heybox_id>; x_xhh_tokenid=<x_xhh_tokenid>' \
  --data-raw 'is_cy=0&link_id=<link_id>&reply_id=<reply_id>&root_id=<root_id>&text=<url_encoded_text>'
```

请求依赖当前网页登录 Cookie，来源请求带有 `Origin: https://www.xiaoheihe.cn` 和 `Referer: https://www.xiaoheihe.cn/`。
