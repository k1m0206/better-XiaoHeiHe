帖子详情和评论区接口文档

该接口用于获取指定帖子的详情、第一页主评论和部分楼中楼回复。

URL: https://api.xiaoheihe.cn/bbs/app/link/tree
Method: GET
Auth: 基于 Cookie

1. 请求参数

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `link_id` | String | 帖子 ID。 |
| `is_first` | String | 首次请求通常为 `1`。 |
| `page` | String | 评论页码，第一页为 `1`。 |
| `index` | String | 评论索引参数，当前实现传 `1`。 |
| `limit` | String | 每页评论数量，当前实现传 `20`。 |
| `owner_only` | String | 是否仅看作者，当前实现传 `0`。 |
| `heybox_id` | String | 当前登录用户 ID。AI Bot 后台请求会从 Cookie 中读取。 |
| `os_type` / `app` / `client_type` 等 | String | Web 端基础环境参数。 |
| `hkey` / `_time` / `nonce` | String | 接口签名参数。 |

2. 响应数据结构

| 路径 | 类型 | 说明 |
| :--- | :--- | :--- |
| `status` | String | `ok` 表示请求成功。 |
| `result.link` | Object | 帖子详情。 |
| `result.link.linkid` | Long | 帖子 ID。 |
| `result.link.title` | String | 帖子标题。 |
| `result.link.text` | String | 帖子富文本正文。 |
| `result.link.description` | String | 帖子摘要或正文片段。 |
| `result.comments` | Array | 评论列表。不同响应中可能包含主评论、楼中楼回复或包裹结构。 |

3. AI Bot 使用约定

AI Bot 使用该接口补全自动回复上下文：

| 字段 | 用途 |
| :--- | :--- |
| `result.link.title` / `result.link.text` / `result.link.description` | 组成帖子标题和正文上下文。 |
| `result.link.user.username` | 作为帖子作者信息。 |
| `result.link.topics` / `tags` / `hashtags` | 组成话题上下文。 |
| `result.comments` | 解析为评论区上下文，最多选取 30 条；评论超过 30 条时优先选取点赞量更高的评论并保持原顺序输出给 AI。 |
| 评论 ID 字段，如 `comment_id` / `commentid` / `id` | 用于定位“@我”的那条评论。 |

如果该接口无法返回 `status=ok`，AI Bot 会记录日志并跳过本次自动回复；如果判断为登录失效，会通知用户并关闭 AI Bot。
