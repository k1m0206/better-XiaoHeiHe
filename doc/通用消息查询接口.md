# 小黑盒通用消息查询接口

## 消息列表接口

用于获取用户的各类消息通知，支持分类筛选。

URL: `https://api.xiaoheihe.cn/bbs/app/user/message`

Method: `GET`

Auth: 基于 Cookie。

### 请求参数

| 参数名 | 类型 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `message_type` | Integer | 消息类型；`16` 表示“@我”，不传或使用其他值时可返回其他分类。 | `16` |
| `list_type` | Integer | 列表类型；`0` 通常表示全部消息。 | `0` |
| `offset` | Integer | 分页偏移量。 | `0` |
| `limit` | Integer | 每页返回数量。 | `20` |
| `heybox_id` | String | 用户唯一标识 ID。 | `<heybox_id>` |
| `os_type` | String | 操作系统类型。 | `web` |
| `hkey` / `nonce` | String | 安全校验与防重放参数。 | - |

### 响应数据结构

| 路径 | 类型 | 说明 |
| :--- | :--- | :--- |
| `status` | String | 请求状态，`ok` 表示成功。 |
| `result.messages` | Array | 消息对象列表。 |
| `result.messages[].user_a` | Object | 发送者信息，包括头像、昵称、等级和勋章。 |
| `result.messages[].text` | String | 消息文本内容。 |
| `result.messages[].timestamp` | String | 消息生成时间戳。 |
| `result.messages[].link` | Object | 关联动态或文章详情。 |
| `result.messages[].link_tag` | Integer | 跳转类型标识。 |

## 消息对象字段

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `message_id` | Long | 消息唯一 ID。 |
| `message_type` | Int | 消息分类。 |
| `text` | String | 消息描述文本。 |
| `timestamp` | String | 消息产生时间戳。 |
| `user_a` / `user_b` | Object | 动作发起人和接收人信息。 |
| `state` | Int | 阅读状态，通常 `0` 为未读。 |
| `link` | Object | 关联内容实体。 |

用户对象通常包含 `username`、`userid`、`avatar`、`level_info` 和 `medals`。关联内容通常包含 `linkid`、`link_tag`、`title`、`description`、`share_url` 和 `forward`。
